# Reference documents

Source documents supplied by the Noreon team, kept in git so they are not lost. They are references, not the implemented clinical specification. The implemented algorithm lives in `docs/clinical/` (NRN-CLIN-ALG-001), and the rules in AGENTS.md still apply there.

Add every guideline, template or protocol Khikar or the clinical team shares to this folder, in the matching subfolder. Keep the original file byte for byte; never edit a copy. A new version is a new file, or a replacement noted in this README.
