1. Instruction to the AI Builder
Build a clickable and functional internal MVP of Noreon focused on the complete user experience. The MVP does
not need full production medical operations. It should simulate or manually support complex parts where needed,
but the user journey should feel real enough for the founding team to test daily.
Do not over-focus on technical architecture. Focus on screens, flows, user behavior, coaching mechanics, daily
routines, mission systems, and the emotional experience of using the product.
2. Product Concept
Noreon is a doctor-monitored preventive medicine and longevity platform. It helps users create a biological and
lifestyle profile, schedule a biomarker blood test, receive a doctor-reviewed insight report, and stay active daily
through Zoe, a caring professional health coach.
3. Core MVP Experience
1. User opens Noreon and understands the promise: a new era of preventive health.
2. User creates a health profile through smooth conversational onboarding.
3. User receives temporary access to Zoe before payment or full biomarker testing.
4. Zoe creates a starter daily routine from user inputs.
5. User sees daily missions, weekly missions, streaks/rhythm tracking, and food-photo guidance.
6. User can simulate booking a biomarker blood test at their location.
7. User can see a sample doctor-reviewed biomarker report.
8. Zoe explains report insights and turns them into daily actions.
9. User continues using the app daily for walking, sleep, food, exercise, and stress habits.

4. Experience Principles
● Start with value, not payment. The user should receive a starter routine and temporary Zoe access before the
biomarker booking conversion.
● Make the app feel caring, scientific, premium, and non-judgmental.
● The interface should be built around Zoe chat, not around a static dashboard.
● Health goals should feel achievable. Avoid overwhelming the user with too many actions.
● Gamification should build momentum without shame. Missed days should trigger recovery coaching, not
punishment.
● Biomarker insights should be described as doctor-reviewed. Zoe should not diagnose disease.
● Sensitive wellbeing, hormonal balance, reproductive health, energy, mood, libido, and fertility should be treated
as part of overall health, not as a separate product vertical.

9. Zoe Response Mechanics
Use this response structure for most Zoe coaching replies:
1. Acknowledge: recognize the user’s situation or emotion.
2. Personalize: refer to their goals, habits, or available profile data.
3. Explain: give a short reason why it matters.
4. Action: recommend one clear next step.
5. Encourage: reduce guilt and create momentum.
Example after missed walk:
“You missed yesterday’s walk, but that does not erase your progress. Since your goal is better metabolic rhythm,
let’s make today easier: take a 12-minute walk after lunch. Small recovery actions matter.”
Example after poor meal:
“This meal is higher in refined carbohydrates than ideal for your current goals. No need to compensate harshly. For
your next meal, add protein and vegetables first, and take a short walk afterward.”

Foundation, Stress Recovery, or Biomarker Readiness.
● Weekly missions should include 3-5 goals, not more.
● Completion target should be 60-80%, not 100%, to avoid perfection pressure.
● Zoe should summarize weekly progress every Sunday or chosen review day.

13. Streaks and Rhythm Mechanics
Use “rhythm” language if “streak” feels too playful. The goal is consistency without shame.
● Track daily check-in rhythm.
● Track food-photo rhythm.
● Track walking rhythm.
● Track sleep wind-down rhythm.
● Allow one grace day per week.
● If a streak is missed, show “Recovery Win” when the user returns.
● Do not show harsh failure states.
Mechanic 	Rule
Grace day 	One missed day per week does not break the rhythm.
Recovery win 	If user returns after missed day, celebrate restart.
Weekly consistency 	Show percentage completion instead of only streak count.
Gentle badges 	Use mature badges: Routine Started, Sleep Rhythm, Food
Awareness, Biomarker Ready, Recovery Win.

16. Food Photo Experience
Food photo guidance is one of the strongest daily engagement mechanics. It should be fast and supportive.
1. User taps “Photograph meal.”
2. User uploads or captures image.
3. App identifies likely foods and asks user to confirm if needed.
4. Zoe gives meal feedback based on user profile.
5. Zoe explains what is good, what to reduce, and what to add.
6. Meal contributes to daily nutrition mission and weekly pattern.
Feedback category 	Example
Good in this meal 	Good protein source; vegetables included; moderate portion.
Watch area 	High refined carbohydrates; low fiber; sugary drink included.
Suggested improvement 	Add protein, reduce bread/rice portion, add salad, replace
soda with water.
Personalized reason 	Because your goal is better metabolic rhythm, this meal may
be improved by balancing carbohydrates with protein and
fiber.

18. Biomarker Test Experience
1. Noreon recommends a first biomarker package based on onboarding.
2. User reviews what is included and why it matters.
3. User selects date, time, and location for blood collection.
4. Zoe sends preparation instructions and reminders.
5. App shows test tracker status.
6. Report is marked as doctor-reviewed before sensitive insights are shown.
7. Zoe explains the report and maps findings to daily actions.
19. Sample Biomarker Report Experience

● Use calm risk wording: low, watch, medium risk pattern, doctor follow-up recommended.
● Avoid broad cancer-risk claims unless validated and reviewed. Use “additional evaluation may be
recommended” wording.
● Connect each insight to daily behavior: food, walking, sleep, exercise, stress, retest timeline.

20. Integrated Sensitive Wellbeing
Do not create a separate “sexual health product.” Treat intimate wellbeing, libido, fertility, reproductive health,
menopause, performance, hormones, energy, mood, and recovery as part of whole-person preventive health.
● This section is optional in onboarding.
● Use discreet, mature language.
● Allow users to skip without penalty.
● Do not diagnose infertility, STI, hormonal disorder, or sexual dysfunction.
● Zoe may explain that sleep, stress, metabolic health, medications, hormones, and emotional pressure can all
affect intimate wellbeing.
● Doctor review is required for sensitive risk interpretations.
21. Payment and Booking Conversion
For the internal MVP, payment can be simulated. The experience should still show where payment will happen
later.
● Do not ask for payment before onboarding and starter routine.
● Ask after user understands what biomarker testing unlocks.
● Conversion CTA: “Book my biomarker test.”
● Secondary CTA: “Continue with starter routine.”
● Show value included: at-home blood collection, lab processing, doctor-reviewed report, Zoe guidance based
on biomarkers.
22. Internal MVP Admin/Doctor Experience
Because this MVP is for internal testing, complex operations can be manual or simulated, but the experience
should exist.
● Admin can see users and onboarding completion.
● Admin can mark biomarker test as scheduled, collected, lab processing, doctor review, report ready.
● Admin/doctor can enter sample biomarker values.
● Doctor reviewer can approve or edit report insights.
● User sees report only after doctor-reviewed status is marked.
23. MVP Acceptance Criteria
● A user can complete onboarding without feeling like they are filling a long medical form.
● A user receives a personalized starter routine before payment.
● A user can chat with Zoe and receive helpful, emotionally intelligent coaching.
● A user can see daily missions, weekly missions, rhythm/streak status, and progress.
● A user can photograph or upload food and receive supportive meal feedback.
● A user can view exercise plans and complete daily movement missions.
● A user can simulate booking a biomarker test at their location.
● A user can see test status progress through report ready.
● A user can view a sample doctor-reviewed biomarker report.
● Zoe can explain report insights in plain language and map them to daily actions.
● Missed goals trigger supportive recovery messages, not failure messages.
● Sensitive wellbeing is integrated into overall health and remains optional/private.
